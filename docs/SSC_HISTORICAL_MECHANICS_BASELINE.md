# 时时彩历史官方玩法机制基线

## 定位

本文件建立的是 **十进制五位数时时彩类玩法的历史官方机制基线**，用于规则校验、数学复算和文章案例生成，不代表任何当前私营/境外/哈希/分分彩平台的现行销售规则、奖金或合法性。

中国财政部、民政部、体育总局在 `财综〔2020〕43号` 中要求高频快开彩票有序退市，并明确 2021 年春节休市结束后全部停止销售。因此，历史中国福利彩票时时彩资料只能作为机制来源，不可写成“当前中国官方 时时彩 正在销售”。

## 核心机制

五位开奖号码按 `万、千、百、十、个` 排列，每位数字域为 `0..9`。

- 一星直选：固定个位，按位相同中奖。
- 二星直选：固定十位+个位，顺序一致中奖。
- 三星直选：固定百位+十位+个位，顺序一致中奖。
- 五星直选：五位全部按位一致中奖。
- 二星组选：十位+个位使用两个不同数字，顺序不限。
- 三星组选3：三位中恰有两个数字相同，所选多重集合一致、顺序不限。
- 三星组选6：三位数字各不相同，所选集合一致、顺序不限。
- 定位1D：指定一个位置和一个数字，对应位置相同中奖。将3D的官方1D机制扩展到时时彩五个位置时，平台仍需确认是否支持该名称及计费方式。
- 后二大小单双：历史重庆时时彩附加玩法中，0-4为小、5-9为大；1/3/5/7/9为单、0/2/4/6/8为双，对十位和个位指定性质。

## 数学基线

设每位独立取 `0..9`，用于**理论组合计数**，不等于对任何具体开奖机制的独立性作平台事实声明。

- k位直选单注覆盖：`1 / 10^k`
- 二星组选一个不同数字对覆盖：`2 / 100 = 1/50`
- 三星组选3一个多重集合覆盖：`3 / 1000`
- 三星组选6一个三数字集合覆盖：`6 / 1000`
- 单位置定位胆一个数字覆盖：`1/10`
- 后二“大小”或“单双”单一性质组合覆盖：`25/100 = 1/4`

## 应用门禁

任何 `分分彩 / 哈希分分彩 / 奇趣分分彩 / 私营平台时时彩` 若要复用这些 mechanics，必须先建立 provider/lottery mapping：

1. 开奖位数与位置顺序一致；
2. 数字域一致；
3. 同名玩法中奖判定一致；
4. 该平台合法投注格式已核验；
5. 单注金额、奖金、返点、限额必须走独立 economics 规则，严禁从本历史基线继承。
