# 用户规则摄取审计（2026-08-11）

本文件记录用户本轮提供资料如何进入内容引擎，防止未来AI把不同证据层级混为一谈。

## 1. 90%金额 / 90%覆盖规则

**处理：采用，但分类为内部硬门禁，不分类为平台官方规则。**

保存：`policies/BET_COMPLIANCE_POLICY.json`

执行：`engine/compliance.py`

已实现：

- 单方案校验；
- 多方案组合校验；
- 同一期/同彩种/同目标中奖空间联合校验；
- 跨玩法统一后取 covered_outcomes 并集；
- 重叠号码去重；
- 覆盖率 > 90% 阻断；
- 金额 > 奖金参考值90% 阻断；
- 高级倍投使用 phase_amounts 分阶段检查；
- target space 未映射时 fail-closed；
- 违规禁止导出。

注意：这套90%阈值来自用户内部策略，不得写成“某彩票平台官方规定”。

## 2. 跨玩法目标空间

**处理：采用原则，并开始做可执行映射。**

`engine/target_spaces.py` 已支持：

- 固定宽度十进制直选号码 → 有序目标空间；
- 固定位置定位胆数字 → 同一有序目标空间；
- 因此可以把“定位胆个位 + 后三直选”统一展开到000–999后计算并集。

未来需继续支持：任选二、任选三、不定位、和值、组选等到目标结果集合的映射。

## 3. 定码轮换三级玩法格式

**处理：格式资料整体保留。**

保存：`formats/dingma_rotation_v1.json`

执行：`engine/format_rules.py`

已固化差异：

- 一级类别 + 玩法类型 + 玩法名称共同决定格式；
- 直选单式 != 直选复式；
- 五位置定位胆 != 单位置定位胆；
- 组三/组六单式必须满足对应重复结构；
- 和值中的21等两位数必须保持为一个原子值；
- 龙虎要求带空格的两个token格式。

四星组选和五星组选的具体平台导入行为仍保留 pending 状态。

## 4. 最大注数表

保存：`formats/dingma_rotation_counts_v1.json`

### 已数学验证

- 三星直选 1000；
- 三星组三 90；
- 三星组六 120；
- 三星混合组选 210；
- 三星单胆码组选包胆 54；
- 二星直选 100；
- 二星组选 45；
- 二星单胆码组选包胆 9；
- 固定四星直选 10000；
- 固定四星组选4=90、组选6=45、组选12=360、组选24=210；
- 五星直选 100000；
- 不定位1/2/3码候选组合空间为10/45/120。

### 数学可推导但平台语义待确认

- 五星组选60：AABCD模式类数 = 840；
- 五星组选120：ABCDE模式类数 = 252。

### 暂不升级为verified

- 任二/任三/任四的最大注数；
- 任二/任三和值类的“最大注数”；
- 龙虎/新龙虎最大注数；
- 所有依赖具体软件“投注一注如何计费/如何拆单”的值。

这些内容保留 user_claims，必须通过目标软件/平台导入和实际注数反馈验证后才能升级。

## 5. 高级倍投

**处理：采用为合规输入模型，而不采用任何固定倍投策略。**

每个 normalized bet 可以提供：

`phase_amounts = {阶段/档位: 当期真实总投注金额}`

组合校验器按每个阶段汇总同目标空间的所有方案，因此 GJBTScheme 等高级倍投不能只用首轮金额通过门禁。

## 6. 用户上传的彩票历史分析分类体系

**处理：提取研究结构，不当成预测规则。**

保存：`knowledge/research/USER_RESEARCH_TAXONOMY_V1.json`

优先吸收：

- 数据质量与规则版本；
- 频率/冷热；
- 遗漏/间隔；
- 重号/邻号/连号；
- 和值/跨度；
- 定位分析；
- 理论概率与蒙特卡洛；
- 随机性审计；
- 时间顺序样本外和walk-forward；
- 多重检验修正；
- 失败实验记录。

高阶机器学习、遗传算法、极窄参数搜索被标记为高过拟合风险；五行、生肖、星座、梦境、字谜等只允许进入 research-only，不可作为已验证技巧事实。

## 7. 后续规则升级原则

任何 user_supplied / pending 项升级为 verified 至少需要满足一种：

1. 官方或目标平台规则来源直接支持；
2. 目标软件实际导入成功并返回可核对的注数/金额；
3. 纯组合数学可以完整枚举证明，且不依赖平台特殊计费/玩法定义。

任何新玩法如果不能映射到明确 target_space，不得绕过组合覆盖校验进入最终导出或可执行文章案例。
