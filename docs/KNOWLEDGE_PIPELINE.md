# Knowledge Pipeline v0.2

## 目标

把采集文章从“可阅读资料”转换为“可约束、可查重、可验证、可持续生成”的知识资产。

## 五层模型

1. **Source Manifest**：来源元数据、Hash、URL；不把来源说法当事实。
2. **Technique Candidate**：从来源识别的技巧原子、位置、彩种、案例数字、风险声明。
3. **Technique Cluster**：把大量近似来源聚成方法族，避免以后按文章数量机械改写。
4. **Verified Rule / Tested Technique**：绑定具体彩种/平台规则并完成数学或历史验证后，才允许用于确定性案例。
5. **Published Registry**：每篇发布文章永久登记，参与标题、搜索意图、技巧组合、案例结构与正文指纹去重。

## 2406篇 brbcw 精选资料如何使用

- 只作为 `unverified_source`。
- `claimed_percentages` 仅保存为待核验声明。
- `稳赚 / 必中 / 保证 / 盈利` 等会进入 `risk_flags`。
- 自动提取出的 `technique_atoms` 是候选标签，不等于技巧有效。
- 文章生成器只有在对应规则已经 `verified` 时，才允许输出合法注数、中奖条件、奖金或赔率说明。

## 为什么不直接“改写2406篇”

大量来源文章本身高度重叠，而且常混有夸张收益、过时玩法、平台广告和未经验证概率。直接改写会造成：

- SEO近重复页面；
- 错误投注规则传播；
- 同一种技巧换标题反复出现；
- 将来源声称误写成事实。

因此系统首先建立“方法族”，以后按**规则 + 技巧原子 + 搜索意图 + 独立案例**生成真正不同的文章。
